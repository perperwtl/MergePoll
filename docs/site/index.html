BEFORE YOU TRY IT

A few useful details.

Start with a small session.
Check the results as you go.

Where can I use MergePoll?

Try it in a class, workshop, community meeting, or small event. It helps when several people need the same explanation or action. Large events have not been tested.

Does MergePoll write the answers?

No. The AI checks which questions can share a response. The organizer provides the answer or takes the requested action.

Can I try it without setup?

Yes. The live demo needs no account or personal API key. The climate walkthrough gives your browser its own example room. You can also create a shared task.

What are the live demo limits?

A shared task lasts 24 hours. It allows 100 submitted questions and 40 live grouping attempts. Each browser can have one active shared task. Shared daily limits also apply. Read the full live demo policy.

Are questions private?

Names do not appear in the question queue. The host can still have access to submitted data. Grouping sends question text and event context to TypeSafe, the AI provider. Do not post private information in the public demo. Read the data and security notes.

Can I run my own copy?

Yes. Use the Docker setup guide. You need your own TypeSafe API key for AI grouping. MergePoll is open source under the AGPL-3.0 license.
