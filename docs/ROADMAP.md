# Roadmap

This is a direction for discussion, not a delivery promise. Changes should be
guided by real organizers and [grouping examples](https://github.com/perperwtl/MergePoll/issues/new?template=grouping_example.yml).

## First: dependable small-event pilots

- Evaluate related-but-distinct, broader/narrower and audience-request examples.
- Improve keyboard navigation and dialog accessibility.
- Add deployment-level abuse controls and model-spending limits.
- Define moderation, retention and deletion behavior.
- Measure organizer corrections, answer-handling time and repeat use.

## Next: separate events

- Multiple independent rooms with organizer ownership.
- Join codes and QR access.
- Background grouping independent of the organizer's browser.
- Event export and explicit data lifecycle controls.

## Later: scale with evidence

- Candidate retrieval before pairwise judgments.
- Load testing, latency budgets and cost measurements.
- More trustworthy supporter identities without requiring public names.
- Multilingual examples and evaluation.

Start a feature request before large changes. Avoid claiming large-event support
or benchmark accuracy until measurements support it.
