# Share MergePoll

## Short description

> MergePoll brings overlapping audience questions and requests into one ranked
> queue when one useful response can satisfy them. Participants ask and vote;
> organizers inspect originals, correct merges and track answered questions.

## A 60-second walkthrough

1. Show two differently worded questions and one related question that needs a
   different response.
2. Run grouping. Inspect what actually merged; do not predeclare a live result.
3. Expand the original questions and explain combined support.
4. Show the organizer splitting a group and marking it answered.
5. Show the GitHub quick start and invite examples that expose mistakes.

Use synthetic questions. Explain that this is a one-room prototype with a
30-open-question limit, and label any fixed screenshots or prepared output.

## Suggested announcement

> I built MergePoll to make live audience Q&A easier to manage. It judges whether
> one concise response can answer several questions, keeps their original wording,
> and lets the organizer correct merges. The experimental source is available
> for free noncommercial and specified institutional use, with source sharing
> for distributed and hosted modifications. Other commercial use needs permission.
>
> Try it locally: https://github.com/perperwtl/MergePoll
>
> I'm looking for organizers of small workshops, lectures and community events
> to test it—and for question pairs that should merge or stay separate.

## Channel order

Start with GitHub and small organizer pilots. Share a short clip and a real
workflow on LinkedIn or relevant communities, respecting their posting rules.
Use Show HN when users can actually run or try the project; a low-friction public
sandbox helps. Consider Product Hunt after successful pilots and polished onboarding.

The [Show HN guidelines](https://news.ycombinator.com/showhn.html) favor something
people can try, ideally without signup barriers. Do not ask for coordinated votes.
The original restricted Sites deployment is not an account-free public sandbox.

## Pilot feedback

- Could attendees join, post and support questions without help?
- Which merges needed correction, and which questions should have merged?
- Did the queue help the organizer answer more efficiently?
- Would the organizer use it again next week?

Repeat use and fewer disruptive mistakes matter more than stars alone.
